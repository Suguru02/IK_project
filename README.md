# IK_project
Учебный проект по ускорению обратного алгоритма кинематики робота "Panda" с помощью обученной модели.

# Цель
- Обучить модель для того чтобы алгоритм обратной кинематики сходился за меньшее количество итераций.

# Процесс
1 Сгенерировать датасет, используя библиотечный алгоритм обратного прохода собрав разные положения суставов. Для каждого сустава генерируем отклонения и повороты получая разные положения. Модель робота - шарнирный робот Panda доступный из библиотеки с помощью rtb.models.DH.Panda(). Выбор обусловлен тем, что это классика индустрии и он предоставлен в библиотеке.

Состав датасета: 
- параметры узлов ( ограничение поворота каждого сустава, нынешнее положение )
- цепочка связей суставов и виртуального узла, с корторым связаны все остальные 
- параметры ребер - их длины
- глобальный признак - целевая позиция хвата

2 Используемые модели. Пробовались разные модели: mlp, TConvGNN, CVAE как с графовым декодером и mlp энкодером, так и наоборот с mlp декодером и графовым энкодером. Выбор графовых моделей обусловлен схожестью манипуляторов с графами по принципу узел графа - сустав манипулятора.

3 Обучение. Все что можно сказать по этому пункту это то что best_metric = 0.1155. Метрика использовалась MAE для 2 величин, а именно среднее отклонение по углу поворота хвата и целевому, а также разницу по положению в координатах. Переменная best_metric зависит от MAE по разнице в координатах и означает отклонение в 11.55 мм. Это огромное отклонение, которое хоть и отличается от 0.2 с которых начинается обучение, но слишком далеко до 0.01 или 0.001, которые можно было бы назвать порогом качества +-. А MAE по углу получилось 0.4 радиана, что тоже плохо влияет на ускорение. Как бы ни пытался это исправить лучше тех метрик, что были названы ранее.

3 Результат. В среднем из 10 был сделан следующий вывод - накладные расходы и слабо обученная модель делают ее использование неэффективным, однако так как это учебный проект знакомство с новыми подходами и моделями было полезным.
